## 💜 Sobre mim

Sou **desenvolvedora em formação**, com base em **Java**, **HTML** e **CSS**. Gosto de entender o *porquê* de cada linha de código e de ver uma interface ganhando forma no navegador.

Hoje estudo **todos os dias** numa rotina de **squad ágil de verdade**: daily, sprints semanais, estimativa em story points, entregas com **code review** e retrospectiva. Cada tarefa vira código versionado no Git.

- 🔭 Construindo agora: **millena-banking**, uma API bancária em **Java + Spring Boot + PostgreSQL**
- 🌱 Próximos passos da minha trilha: testes automatizados, segurança com JWT, Docker e React
- 💬 Pode me perguntar sobre: **Java**, **HTML semântico** e **layout com CSS/Flexbox**
- 📫 Fale comigo: **mimarc.camargo@gmail.com**
